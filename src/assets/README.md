# 地图底图数据说明（world_cn.json / dashline.json）

本目录下的两份 GeoJSON **不是单一来源的数据**，而是两份公开数据拼合、再经几何处理后的产物。

## 构成

### 1. 中国部分（含台湾、藏南、钓鱼岛、南海诸岛）——高德/阿里 DataV 审定数据

- **来源**：阿里 DataV · GeoAtlas（datav.aliyun.com）发布的 100000_full（中国全图）
  GeoJSON，该数据带自然资源部**审图号：GS京(2022)1061 号**，即国家审定的标准画法，
  已由 GCJ-02 坐标系转为 WGS84。
- **内容**：文件中是 1 个中国 feature（MultiPolygon，252 个子多边形），涵盖
  中国大陆、台湾岛、海南岛、钓鱼岛/赤尾屿、南海诸岛、藏南地区、黑瞎子岛等，
  全部按审定画法绘制。
- **配套**：`dashline.json` 为南海十段线，同样来自上述 DataV 中国全图数据，
  作为独立要素渲染。

### 2. 其他 235 个国家/地区——Natural Earth（公有领域）

- **来源**：Natural Earth（naturalearthdata.com）行政区划矢量数据，
  国际通用公开数据集。它只负责"中国以外的世界长什么样"。
- **注意**：Natural Earth 的原始画法存在**不符合中国立场**之处
  （把藏南划入印度、科索沃独立成国、中不边界画法等），且其边界
  **未经任何中国审定**。

## 关键几何处理（构建期完成）

为避免两份数据重叠（如 Natural Earth 的印度覆盖藏南），以**中国多边形为唯一权威基准**：

1. 其他所有国家/地区的多边形都执行了 `该国多边形 − 中国多边形`（shapely
   difference），把中国审定边界内的区域从中国以外的所有 feature 中挖除；
2. 归属调整：藏南（达旺等）归中国、中不边界争议区归中国、科索沃并入塞尔维亚、
   索马里兰并入索马里、北塞浦路斯并入塞浦路斯；
3. 数值验证：中国∩印度、中国∩不丹的几何交集面积均为 0；达旺、瓦弄等争议点
   坐标仅落在中国多边形内；各 feature 两两不重叠。

由此，**主权归属在数据层已固定**，与渲染顺序、投影方式无关，任何投影下
争议区都不可能画到别的国家里。

## 边界与责任声明

- 审图号 GS京(2022)1061 号 审定的**仅中国这张底图本身**；
- 其他国家边界遵循 Natural Earth 的国际通行画法，**不代表中国官方立场**；
- 本数据用于地图填色可视化，不构成任何法律意义上的边界主张依据。
